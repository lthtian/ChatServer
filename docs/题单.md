### 题单

侧重数轴移动、操作次数与取模统计，配合《携程秋招编程题整理》第一份第 2 题“取模加权求和”练习。下面只写题意和推荐理由，不附解法；题目名称链接直接进入练习页。

#### 一、移动与最少行动次数

- [ ] **1. [力扣 1033：移动石子直到连续](https://leetcode.cn/problems/moving-stones-until-consecutive/)** · 中等 · 优先
  - 题意：数轴上有三颗石子，每次把一颗端点石子移到两端之间的空位，求最终连续时的最少和最多移动次数。
  - 相似点：规则很短，但位置关系和特殊间隔容易让分类遗漏；适合练习证明分类是否完整。
  - 来源：力扣题库。

- [ ] **2. [力扣 754：到达终点数字](https://leetcode.cn/problems/reach-a-number/)** · 中等 · 优先
  - 题意：从数轴上的 0 出发，第 i 次必须移动 i 格，方向可左可右，求到达目标的最少移动次数。
  - 相似点：与刚讨论的跳跃题最接近，都需要处理越过目标、反向移动和最少步数；但本题没有位置边界，步长规则也不同。
  - 来源：力扣题库。

- [ ] **3. [力扣 991：坏了的计算器](https://leetcode.cn/problems/broken-calculator/)** · 中等
  - 题意：从 startValue 出发，每次只能乘 2 或减 1，求到达 target 的最少操作次数。
  - 相似点：两种操作影响差异很大，适合检验“先做某类操作，再做另一类”的分类是否真的覆盖最优方案。
  - 来源：力扣题库。

#### 二、取模与批量统计

- [ ] **4. [牛客：被 3 整除](https://www.nowcoder.com/practice/51dcb4eef6004f6f8f44d927463ad5e8)** · 热身
  - 题意：数列第 i 项是把 1 到 i 依次拼接得到的整数，统计第 l 到 r 项中能被 3 整除的项数。
  - 相似点：题面似乎需要构造巨大数字，实际考察如何从表达式中提取必要信息；适合作为取模思维的热身。
  - 来源：网易校招笔试，见下方来源核对。

- [ ] **5. [牛客：数对](https://www.nowcoder.com/practice/bac5a2372e204b2ab04cc437db76dc4f)** · 优先
  - 题意：统计满足 1 <= x, y <= n 且 x % y >= k 的有序数对数量，n 最大为 10^5。
  - 相似点：与“取模加权求和”非常接近，同样需要观察除数变化时的余数分布，避免对所有组合逐个计算。
  - 来源：网易校招笔试，见下方来源核对。

- [ ] **6. [力扣 1862：向下取整数对和](https://leetcode.cn/problems/sum-of-floored-pairs/)** · 困难 · 进阶
  - 题意：对数组中所有有序下标对求 floor(nums[i] / nums[j]) 的总和，结果对 10^9 + 7 取模。
  - 相似点：虽然算的是整数商，但与取模加权求和都涉及大量整数除法相关的求和；适合在“数对”之后练习，难度更高。
  - 来源：力扣题库。

#### 三、面试中的操作建模

- [ ] **7. [力扣 453：最小操作次数使数组元素相等](https://leetcode.cn/problems/minimum-moves-to-equal-array-elements/)** · 中等
  - 题意：每次让 n - 1 个数组元素同时加 1，求使所有元素相等的最少操作次数。
  - 相似点：不靠复杂数据结构，重点是如何理解一次操作、避免逐步模拟，并证明最少次数。
  - 来源：力扣题库；牛客有网易游戏雷火一面回忆帖记载同题意，属于个人面经，非公司官方确认。

#### 推荐顺序与来源核对

- **先做最贴近的三道：1033 → 754 → 数对。** 再补 991、453；取模方向可先用“被 3 整除”热身，最后挑战 1862。
- 力扣难度沿用题面；“优先、热身、进阶”是本题单的练习建议。
- “数对”和“被 3 整除”的校招来源：[牛客企业版收录的网易 2018 春招笔试题解](https://hr.nowcoder.com/article/1622)。该页面含解法，可做完后再看。
- 453 的面经线索：[一个小硕的面筋回报帖](https://www.nowcoder.com/discuss/353154856925995008)，见“网易游戏雷火一面”部分。其余力扣题按相似性选入，不标注未经核实的公司面试来源。
